# Signal Intake Rules

Prioritize:
- The latest 3 to 5 high-signal events from Event Library.
- Penalty cases before routine notices.
- Repeated regulators, repeated themes, and repeated control failures.
- Events with verified source links, article-level evidence, and real institution names.

Deprioritize:
- Raw counts without interpretation.
- Duplicate wording across multiple announcements.
- Generic administrative notices that do not change control expectations.

Use only:
- Current window evidence.
- Source-backed article text.
- Event IDs and original source links.
- The strongest control signal, not the full announcement chronology.
